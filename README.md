# FitLab + CREED public runtime assets

Small public website/application assets used by FitLab and CREED. Identical body-map vectors and movement dictionaries are shared by both apps. Production URLs pin an exact Git commit.

This repository intentionally contains no user photos, personal histories, payment data, credentials, environment files, server code, fonts, screenshots of conversations, backups, or videos. Original files remain on the application origin for fallback and offline installation.

Brand and content rights remain with their respective owners. Public availability is not a blanket license for unrelated reuse. No third-party fonts are redistributed.
